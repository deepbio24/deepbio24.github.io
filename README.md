# Deepak Kumar Singh Website

Static profile website built from Deepak's CV and profile photo.

## Files

- `index.html` - Main website page.
- `projects.html` - Dedicated project page with full figure grid and project details.
- `styles.css` - Responsive visual styling.
- `assets/deepak-profile.png` - Profile photo used in the hero.
- `assets/Deepak-Kumar-Singh-CV.pdf` - Downloadable CV.
- `assets/experiment-design.jpeg`, `assets/result-*.png`, and `assets/project2-icon*.png` - Project figures imported from the older website archive.

Open `index.html` in a browser to view the site.
